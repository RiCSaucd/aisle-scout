# Intellectual property (not legal advice)

This is a founder checklist. A licensed patent attorney should file. Aisle Scout is **not** “patent pending” until the USPTO issues a receipt.

## Clock that already started

The GitHub repo is **public**. In the US you generally have **12 months** from first public disclosure to file (35 U.S.C. § 102 grace period). First public commits were mid-September 2026. Treat **September 2027** as a hard deadline. Many other countries have **no** grace period — file a provisional **before** more demos, ads, or App Store listings if you care about foreign rights.

## What might be protectable (ask counsel)

Software that is “compare grocery prices” is usually an abstract idea. Stronger stories are **specific technical methods**, for example:

- In-aisle shelf log **overrides** retailer API / website quotes for the same SKU + store
- RSA-signed Walmart I/O Affiliate lookup keyed to store 579, merged only when no shelf log exists
- Photo inventory → expiry → cook-from-stock, with official list push to Instacart
- Trip optimizer that treats bulk clubs as far/bulk and amortizes membership

Counsel will search [USPTO Patent Public Search](https://ppubs.uspto.gov/pubwebapp/) and Google Patents before drafting.

## File this week (provisional)

1. Call a Florida patent attorney (USPTO is federal; Florida has no state patent office).
2. Micro-entity fee is low (on the order of **$75–150** if you qualify) plus attorney draft (~$1.5k–4k typical for a careful provisional).
3. File via [USPTO Patent Center](https://www.uspto.gov/patents/apply/patent-center). You get a filing date. You may then say **Patent pending**.
4. You have **exactly 12 months** to file a nonprovisional. That one is the expensive examination.

Do **not** file a thin one-pager. The provisional only covers what it actually describes and draws.

## Also this month (cheaper, often more useful)

- **Trademark** “Aisle Scout” in class 9 (software) and 35 (shopping information) at [USPTO TESS / TEAS](https://www.uspto.gov/trademarks). Branding money is wasted if the name is taken.
- Keep this repo **All rights reserved** (see `LICENSE`). Public source is not a license to clone.
- Copyright in the code and photos is automatic; register if you will send takedowns.

## Do not

- Put “Patent pending” in the app or ads until you have the filing receipt
- Pitch overseas VCs before a provisional if you want those countries
- Describe the override algorithm in a tweet thread before counsel has the draft
